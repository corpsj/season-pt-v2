# season-pt_v2 Implementation Plan

> **For agentic workers:** Implement task-by-task. Visual detail (every hex/px, per-screen layout, navigation, seed data) lives in `docs/DESIGN_SPEC.md` — treat it as authoritative and read the relevant §C screen entry before building a screen. Architecture in `docs/superpowers/specs/2026-06-22-season-pt-v2-design.md`.

**Goal:** Build the 계절 PT C-plan trainer+member mobile PWA (29 screens) on Next.js 16 / React 19 / Tailwind 4 / Supabase, reusing the existing Supabase(Seoul)+Vercel environment, deployed from a new repo.

**Architecture:** UI-first. Shared design-system primitives + typed mock data layer first; all screens built against mock repositories; then swap repositories to Supabase (fresh schema) and wire auth (trainer=Supabase Auth id-only, member=custom session). Mobile single-frame, RSC + Server Actions.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind 4 (`@theme`), `@supabase/ssr`, Bun, Pretendard + Cormorant Garamond, custom Icon set (81).

## Global Constraints
- Visual truth = inline hex/px in `DESIGN_SPEC.md`. Do NOT use Wanted DS blue (#3366FF). Warm/sage palette only.
- Korean UI, 해요체. Mobile frame 380×812 (desktop preview); full-screen + safe-area on device.
- Primary sage `#768C6A`, ink `#4B3B2E`, canvas `#EAE5DB`, surface `#FAF8F4`, card `#fff`, terracotta `#C67352`.
- All screen-enter uses `.scr` (ptUp); disable under `prefers-reduced-motion`.
- Deploy: function region MUST be `icn1` (Seoul). Verify `x-vercel-id: icn1::icn1`.
- Commit author email `corpsjld01@gmail.com`. Commit frequently (one per task).
- Verification gate per phase: `bunx tsc --noEmit` · `bunx eslint` · `bun run build` clean.
